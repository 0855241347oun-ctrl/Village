# 🏡 ระบบบริหารจัดการข้อมูลประชากรและบ้านเรือนในหมู่บ้าน (Village Management System)

เอกสารสรุปการพัฒนา **เวอร์ชัน 1.0.0 (Initial Release)** และ **แผนการพัฒนาในอนาคต (Roadmap)**

---

## 📌 1. สิ่งที่ได้ดำเนินการและพัฒนาในเวอร์ชันแรก (Version 1.0.0)

ในเวอร์ชันปัจจุบัน ระบบถูกออกแบบและพัฒนาขึ้นเพื่อรองรับการจัดเก็บและบริหารจัดการข้อมูลหมู่บ้านอย่างเป็นระบบ โดยมีฟีเจอร์หลักดังนี้:

### 🔐 1.1 ระบบยืนยันตัวตนและการกำหนดสิทธิ์ผู้ใช้งาน (Authentication & User Roles)
- **ระบบ Login / Logout**: ยืนยันตัวตนผู้ใช้ผ่านบริการ Supabase Auth
- **การแบ่งสิทธิ์ผู้ใช้งาน (Role-Based Access Control - RBAC)**:
  - `super_admin`: มีสิทธิ์สูงสุดในการจัดการโซนการปกครอง และจัดการบทบาทของผู้ใช้อื่นๆ ในระบบ
  - `user`: เจ้าหน้าที่ทั่วไป มีสิทธิ์ดู เพิ่ม แก้ไข และลบข้อมูลบ้านและลูกบ้าน
- **Auto Profile & Super Admin Assignment**: ระบบสมัครสมาชิกใหม่จะสร้าง Profile อัตโนมัติ โดยผู้สมัครคนแรกของระบบจะได้สิทธิ์ `super_admin` โดยอัตโนมัติผ่าน Database Trigger

### 🗺️ 1.2 ระบบจัดการโซน/พื้นที่การปกครอง (Zone Management)
- จัดกลุ่มบ้านเรือนออกเป็นโซน (เช่น โซน A, B, C, D)
- เพิ่ม แก้ไข ลบ ข้อมูลโซน (จำกัดสิทธิ์เฉพาะ `super_admin`)

### 🏠 1.3 ระบบจัดการบ้านเรือน (House Management)
- บันทึกเลขที่บ้านและรายละเอียดที่อยู่ โดยผูกข้อมูลไว้กับโซนที่เลือก
- กรองและค้นหาบ้านเรือนแยกตามโซน
- แก้ไขและลบข้อมูลบ้านเรือน

### 👤 1.4 ระบบจัดการประชากร/ลูกบ้าน (Resident Management)
- บันทึกข้อมูลลูกบ้านอย่างละเอียด ได้แก่:
  - ชื่อ-นามสกุล, ชื่อเล่น, เลขประจำตัวประชาชน (ID Card)
  - วันเดือนปีเกิด, ระดับการศึกษา, สถานภาพการสมรส
  - เบอร์โทรศัพท์ติดต่อ และหมายเหตุเพิ่มเติม
- **การระบุหัวหน้าครัวเรือน (`is_head_of_house`)**: สามารถเช็กระบุว่าลูกบ้านคนใดเป็นหัวหน้าบ้าน
- **หน้าแสดงรายละเอียดลูกบ้าน (Resident Detail Page)**: แสดงประวัติและข้อมูลส่วนบุคคลอย่างเป็นระเบียบ

### 📊 1.5 หน้าสถิติและภาพรวม (Dashboard Overview)
- การสรุปยอดรวม (Summary Metrics): จำนวนประชากรทั้งหมด, จำนวนบ้านเรือน, จำนวนโซน และจำนวนผู้ใช้งานระบบ
- แผนภูมิสถิติ (Charts): แสดงสถิติจำนวนบ้านเรือนแยกตามแต่ละโซน

### 🔒 1.6 ความปลอดภัยและการจัดการโค้ด (Security & Repository Setup)
- **Supabase Row Level Security (RLS)**: ป้องกันการเข้าถึงและแก้ไขข้อมูลข้ามสิทธิ์ในระดับ Database Policy
- **Git & Environment Security**: ปรับปรุง `.gitignore` ซ่อนคีย์ความลับใน `.env` ไม่ให้รั่วไหลขึ้น GitHub Repository

## 🚀 2. แผนการพัฒนาในอนาคต (Future Roadmap)

เพื่อยกระดับระบบให้ครอบคลุมการใช้งานจริงของชุมชนและองค์กรปกครองส่วนท้องถิ่น เอกสารนี้แบ่งแผนการพัฒนาออกเป็น 2 มิติ:

---

### 🗣️ 2.1 ในมุมมองผู้ใช้งานและภาษาพูด (User & Business View)

#### 1. 🔍 ระบบค้นหาอัจฉริยะ (Smart Search & Quick Filter)
> *"พิมพ์คำเดียวเจอเลย ทั้งชื่อ เลขบ้าน หรือเบอร์โทร"*
- ค้นหาลูกบ้านได้ทันทีจากช่องค้นหาเดียว (Global Search)
- กรองข้อมูลประชากรตามช่วงอายุ (เช่น กลุ่มเด็ก, วัยทำงาน, ผู้สูงอายุ 60 ปีขึ้นไป)

#### 2. 📄 ระบบออกเอกสารและรายงาน (Export & Report Generation)
> *"กดปุ่มเดียวได้รายงานไปใช้งาน หรือพิมพ์หนังสือรับรองได้ทันที"*
- ส่งออกข้อมูลลูกบ้านและทะเบียนบ้านเป็นไฟล์ **Excel (XLSX)** หรือ **PDF**
- ออกหนังสือรับรองการเป็นผู้อยู่อาศัยในหมู่บ้านสำหรับเจ้าหน้าที่เซ็นอนุมัติ

#### 3. 🏥 ระบบติดตามสวัสดิการและกลุ่มเปราะบาง (Welfare & Vulnerable Groups)
> *"ดูแลลูกบ้านกลุ่มพิเศษได้อย่างทั่วถึง"*
- ติดแท็ก (Tag) ระบุลูกบ้านที่เป็น **ผู้สูงอายุ, ผู้ป่วยติดเตียง, ผู้พิการ หรือผู้มีรายได้น้อย**
- บันทึกประวัติการได้รับสวัสดิการ เช่น ถุงยังชีพ, เบี้ยยังชีพผู้สูงอายุ

#### 4. 📢 ระบบแจ้งเตือนข่าวสารหมู่บ้าน (Village Announcements & LINE Notice)
> *"แจ้งข่าวสารและเก็บค่ากลางผ่าน LINE ได้สะดวก"*
- เชื่อมต่อ **LINE Official Account (LINE OA)** หรือ SMS เพื่อส่งข่าวสาร นัดหมายประชุมหมู่บ้าน
- ระบบติดตามการชำระค่าขยะ/ค่าส่วนกลางของแต่ละบ้าน

#### 5. 📸 ระบบแนบรูปภาพและเอกสารสำคัญ (Image & Document Attachments)
> *"มีรูปถ่ายลูกบ้านและสำเนาเอกสารเก็บไว้ในระบบ"*
- อัปโหลดรูปถ่ายหน้าตรงของลูกบ้าน
- แนบสำเนาทะเบียนบ้าน/บัตรประชาชนกำกับไว้ในระบบอย่างปลอดภัย

---

### 🛠️ 2.2 ในมุมมองทางเทคนิค (Technical View)

#### 1. 🛑 Data Validation & Form Sanitization
- ใช้ **Zod** หรือ **Yup** ร่วมกับ `react-hook-form` เพื่อตรวจสอบความถูกต้องของข้อมูลก่อนส่งไปยัง Server
  - ตรวจสอบความถูกต้องของ **เลขบัตรประชาชน 13 หลัก** (Checksum Check)
  - ตรวจสอบรูปแบบเบอร์โทรศัพท์ และรูปแบบวันที่

#### 2. 📜 Audit Logging & Activity Tracking
- สร้างตาราง `activity_logs` เพื่อบันทึกการกระทำของผู้ใช้งาน (ใคร เพิ่ม/แก้ไข/ลบ ข้อมูลอะไร เมื่อไหร่) สำหรับตรวจสอบย้อนหลังทางกฎหมายและความปลอดภัย

#### 3. ⚡ Server-Side Pagination & Performance Optimization
- ปรับเปลี่ยนการดึงข้อมูลจากดึงทั้งหมด (Fetch All) มาเป็น **Pagination / Infinite Scroll** ในระดับ Supabase Query เพื่อรองรับประชากรจำนวนหลายหมื่นคนโดยไม่ทำให้หน้าเว็บช้าลง

#### 4. 📱 Progressive Web App (PWA) & Offline Mode
- ทำระบบให้เป็น **PWA** รองรับการติดตั้งบนสมาร์ตโฟน/แท็บเล็ต
- รองรับการลงพื้นที่เก็บข้อมูลแบบไม่มีสัญญาณอินเทอร์เน็ต (Offline Caching ด้วย Service Workers & IndexedDB) แล้ว Sync ข้อมูลเมื่อกลับมาเชื่อมต่อเน็ต

#### 5. 🧪 Automated Testing & CI/CD Pipeline
- เขียน **Unit Tests** & **Integration Tests** ด้วย Vitest สำหรับฟังก์ชันการคำนวณและดึงข้อมูล
- ตั้งค่า **GitHub Actions** ตรวจสอบการ Build และ Run Test อัตโนมัติทุกครั้งที่มีการ Push โค้ดขึ้น Repository

## 🛠️ 3. การติดตั้งและเริ่มต้นใช้งาน (Getting Started)

```bash
# 1. Clone repository
git clone https://github.com/0855241347oun-ctrl/Village.git

# 2. เข้าสู่โฟลเดอร์โปรเจกต์
cd Village

# 3. ติดตั้ง Dependencies
npm install

# 4. ตั้งค่า Environment Variables (.env)
# คัดลอกไฟล์ .env.example เป็น .env แล้วใส่ค่า Supabase Credentials
cp .env.example .env

# 5. รันโปรเจกต์ในแบบ Development
npm run dev
```
